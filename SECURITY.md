# Política de segurança

## Como reportar uma vulnerabilidade

Não abra issue pública para vulnerabilidades.

Use o reporte privado do GitHub: aba **Security** → **Report a vulnerability**
(https://github.com/nfe/rtc-calculadora-offline/security/advisories/new).

Inclua a versão ou o commit afetado, os passos para reproduzir e o impacto.
Use somente dados sintéticos. Não envie dados reais de contribuintes.

## O que esperar

- Suporte em regime de melhor esforço, sem SLA.
- Fazemos divulgação coordenada: publicamos o advisory depois da correção.
- Vulnerabilidades no código de origem são da Receita Federal do Brasil.
  Reporte-as também nos repositórios oficiais listados em NOTICE.

## Versões suportadas

Somente a versão mais recente da branch `main`.
